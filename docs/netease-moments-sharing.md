# 通过网易云音乐发送 Apple Music 歌曲链接

1. 安装 AM++ 模块 APK。给模块勾选 Apple Music 和网易云音乐作用域并重启两者。
2. 在 AM++ 的「界面与底栏」开启「微信朋友圈分享」。
3. 在 Apple Music 的系统分享面板选择「分享到朋友圈（歌曲链接）」。核对歌名、歌手和链接，再选择「打开网易云分享面板」。
4. 在网易云原生面板选择朋友圈，在微信内确认发布。

默认保留原链接。可开启中国大陆地区选项，仅把链接地区字段改为 `cn`，保留曲目 ID 和其他查询参数。确认页支持复制链接、使用其他分享应用及保存本地草稿。草稿只用于相同曲目的链接，24 小时后失效。

网易云适配按官方签名和精确版本匹配。目前登记 9.5.81（9005081）和 9.6.22（9006022）。桥接仅在网易云主进程运行，接收器要求 AM++ 签名权限。只有携带对应链接的网易云分享面板恢复后才报告已打开。等待超时或版本不匹配时可复制链接或走系统分享。模块无需微信作用域，最终发布由用户确认。

自动化测试覆盖链接校验、地区改写、确认页、草稿、网易云桥接和原生契约。实际朋友圈卡片的展示和设备上的跨应用流程仍需真机验证。
